MiniLisp

Небольшой интерпретатор Lisp на Haskell.

  $ stack exec lisp-exe
  REPL
  > (defun fact (n) (cond ((< n 2) 1) (t (* n (fact (- n 1))))))
  fact
  > (fact 5)
  120
  > ^D
  Bye.


Язык

Литералы: целые (42, -7),
  числа с плавающей точкой (3.14, 1e3),
  строки ("hi", без escape-последовательностей, в одну строку),
  символы (foo), nil / (), t. Кавычка: 'x / '(1 2 3).
  Комментарий — от ; до конца строки.

Истинность: ложен только nil.

Специальные формы:

  (quote x) / 'x            без вычисления
  (cond (тест тело...) ...) первый не-nil тест побеждает; если ни один — nil
  (lambda (параметры...) тело...)
                            лексическое замыкание; имена параметров уникальны
  (let ((имя выраж) ...) тело...)
                            параллельное связывание; имена уникальны
  (setq имя выраж ...)      присваивание только существующей привязке
  (apply f список-аргументов)
                            список аргументов — правильный список
  (defun имя (параметры...) тело...)
                            только верхний уровень; рекурсивно

Примитивы:

  Арифметика: + - * div mod abs / — + - * остаются целыми, пока не
  появится float; / всегда float; div/mod только целые, деление на
  ноль — ошибка.

  Сравнение: < > <= >= = /= (смешанные int/float допустимы).

  Равенство: eq (символы/примитивы/nil), eql (плюс числа одного типа),
  equal (структурное).

  Списки: cons car cdr list null listp consp atom.

  Типы: numberp symbolp.


Семантика

Лексическая область видимости.
  (let ((y 10)) ((lambda (x) (+ x y)) 5)) => 15

Рекурсия.
  defun замыкается на окружение, которое уже содержит его собственное
  имя, поэтому тело может вызывать себя.

setq локален.
  Меняет привязки только в текущем фрейме.
  (let ((x 1)) ((lambda () (setq x 2))) x) => 1
  Замыкания захватывают по значению, изменяемых ячеек нет.

setq требует существующей привязки.
  (setq zzz 1) — это eval error; вводите имена через let или defun.

t нельзя затенять.


REPL

Приглашение "> "; продолжение "... " пока не сбалансируются скобки.

Окружение верхнего уровня сохраняется между формами: defun и мутации,
дошедшие до верхнего уровня, переживают ввод.

Ctrl-D на "> " — выход. Ctrl-D посреди формы отдаёт частичный ввод
парсеру, тот печатает parse error.

Ошибки печатают parse error или eval error; цикл продолжается,
окружение не тронуто.


Сборка

  stack build
  stack test      автономный тестовый набор; ~237 случаев
  stack run       запустить REPL


Структура

  src/MiniLisp/Types.hs     Value, Env, consValue, Show
  src/MiniLisp/Parser.hs    ридер: String -> Maybe [Value]
  src/MiniLisp/Eval.hs      eval :: Env -> Value -> Maybe (Env, Value)
  src/MiniLisp/Repl.hs      IO-REPL (сохраняемое окружение, многострочный ввод)
  app/Main.hs               точка входа: repl
  test/Tests.hs             тестовый набор
